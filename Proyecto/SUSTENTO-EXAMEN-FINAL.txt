2. Datos: EF Core con migraciones; repositorio simple para entidad

Archivos o carpetas a mostrar:
- D:\Cibertec\Proyecto\SistemaComercial\SistemaComercial.Infrastructure\ApplicationDbContext.cs
- D:\Cibertec\Proyecto\SistemaComercial\SistemaComercial.Infrastructure\Migrations
- D:\Cibertec\Proyecto\SistemaComercial\SistemaComercial.Dominio\Cargos\ICargoRepository.cs
- D:\Cibertec\Proyecto\SistemaComercial\SistemaComercial.Infrastructure\Repositories\CargoRepository.cs

Como sustentar:
Se usa Entity Framework Core como acceso principal a datos y las migraciones estan registradas en la carpeta Migrations. Para la entidad Cargo existe un repositorio simple con su interfaz en Dominio y su implementacion en Infrastructure.

Como generar una nueva migracion:
Desde la carpeta de la solucion:
D:\Cibertec\Proyecto\SistemaComercial

Ejecutar:
dotnet ef migrations add NombreDeLaMigracion --project .\SistemaComercial.Infrastructure\ --startup-project .\SistemaComercial.Api\

Ejemplo:
dotnet ef migrations add AgregarFiltroCargos --project .\SistemaComercial.Infrastructure\ --startup-project .\SistemaComercial.Api\

Para aplicar la migracion a la base de datos:
dotnet ef database update --project .\SistemaComercial.Infrastructure\ --startup-project .\SistemaComercial.Api\

Como explicarlo:
Cuando hago cambios en las entidades o configuraciones del modelo, genero una nueva migracion con dotnet ef migrations add. Entity Framework Core compara el modelo actual contra el ModelSnapshot y crea los archivos nuevos dentro de Infrastructure\Migrations.

Ejemplo practico para sustentar:
Si quiero generar una migracion de prueba, puedo cambiar la longitud del correo empresarial del empleado en:
D:\Cibertec\Proyecto\SistemaComercial\SistemaComercial.Infrastructure\Configurations\EmpleadoConfigurations.cs

Linea a ubicar:
builder.Property(e => e.CorreoEmpresarial)
    .HasMaxLength(100)

Ejemplo de cambio:
Cambiar HasMaxLength(100) por HasMaxLength(120)

Luego generar la migracion:
dotnet ef migrations add CambiarLongitudCorreoEmpleado --project .\SistemaComercial.Infrastructure\ --startup-project .\SistemaComercial.Api\

Y si quiero aplicarla a la base:
dotnet ef database update --project .\SistemaComercial.Infrastructure\ --startup-project .\SistemaComercial.Api\

Como decirlo:
Para demostrar el uso de migraciones, puedo modificar una restriccion del modelo, por ejemplo la longitud maxima del correo empresarial del empleado. Despues genero una nueva migracion y EF Core registra ese cambio en la carpeta Migrations.

17. Fecha con date pipe

Archivo a mostrar:
- D:\Cibertec\Proyecto\sistema-comercial-app\src\app\pages\empleados\empleados.html

Como sustentar:
Adicionalmente, en la pantalla de empleados se muestra la fecha de ingreso usando el date pipe de Angular con el formato dd/MM/yyyy, para evidenciar el formateo de fechas en la vista.

Que significa pipe:
Un pipe en Angular es un transformador visual que se usa en el HTML para cambiar la forma en que se muestra un dato, sin modificar su valor original. En este caso, el date pipe toma la fecha recibida desde la API y la presenta con un formato legible para el usuario.
