La Tarea 11 consiste en continuar el desarrollo de la aplicacion SPA del proyecto SistemaComercial utilizando Angular y Bootstrap.

--- LO QUE SE IMPLEMENTO ---

Como primer paso, se instalo Bootstrap en el proyecto Angular mediante npm.

Luego, Bootstrap se configuro de forma global en el archivo angular.json para que sus estilos puedan utilizarse en toda la aplicacion SPA.

Con esta base, se adapto la pantalla de login utilizando clases y estructura visual de Bootstrap, manteniendo el flujo de autenticacion por empleado.

Tambien se creo un nuevo componente standalone llamado navbar, el cual se integro dentro de la pantalla de cargos para reforzar la estructura SPA de la aplicacion.

Finalmente, se reestructuro la pantalla de cargos con una presentacion mas ordenada usando Bootstrap, incorporando encabezado, tarjeta de resumen y tabla responsive.

Para facilitar la prueba de la SPA, el frontend se configuro para consumir la
API publicada previamente en Azure App Services, evitando depender de una API
local durante la revision.
