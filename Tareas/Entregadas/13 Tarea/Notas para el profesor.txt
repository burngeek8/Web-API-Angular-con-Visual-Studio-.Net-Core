--- LO QUE SE IMPLEMENTÓ ---

Se continuó el proyecto sistema-comercial-app creando una nueva pantalla de listado de empleados dentro de la SPA ya implementada.

Para ello se implementó:

- un modelo Empleado
- un servicio EmpleadoService para consumir la API

En la carpeta Proyecto de la entrega se adjuntan tanto la aplicación Angular como la API, ya que el trabajo principal se realizó en la SPA, pero fue necesario un ajuste de permisos en el backend para completar la prueba funcional del listado.
